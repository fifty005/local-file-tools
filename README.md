# PDF Combiner

A private, browser-only PDF combiner. PDF files are opened, previewed, combined, and downloaded on the user's device; this site does not send document data to a server.

## Publish with GitHub Pages

1. Create a public GitHub repository.
2. Push this folder to its `main` branch.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/(root)`.
5. Save and share the Pages URL with your family.

GitHub Pages hosts only the app files. Each visitor's PDFs remain on their own device.
